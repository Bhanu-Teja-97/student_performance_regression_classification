# student_performance_regression_classification# Student Performance Analysis 📊

## About the Project
This project focuses on analyzing student academic performance using Python and data visualization techniques. It explores how factors like study hours, attendance, parental education, and extracurricular activities relate to students' academic scores.

## Dataset
The dataset contains student information such as:
- Math Score
- Reading Score
- Writing Score
- Attendance Percentage
- Study Hours Per Week
- Parental Education
- Extracurricular Activities
- Pass/Fail Status

## Data Preprocessing
- Handled missing values.
- Removed duplicate rows and columns.
- Corrected inconsistent categorical values.
- Generated unique IDs for missing student IDs.
- Detected and removed outliers using the IQR method.
- Saved the cleaned dataset as a new CSV file.

## Exploratory Data Analysis (EDA)

### Univariate Analysis
- Math Score Distribution – Histogram
- Reading Score Distribution – Boxplot
- Parental Education – Countplot
- Extracurricular Participation – Pie Chart

### Bivariate Analysis
- Math Score vs Reading Score – Scatter Plot
- Study Hours vs Math Score – Regression Plot
- Parental Education vs Writing Score – Boxplot
- Extracurricular Activities vs Pass/Fail – Countplot

### Multivariate Analysis
- Correlation Heatmap
- Pairplot
- Violin Plot
